# 基金持仓看板 astrbot_plugin_fund_board

这是一个 AstrBot 插件，可以在聊天里记录基金持仓、查看盘中估值和盈亏，也支持发送 App 持仓页截图一键导入持仓。

## 安装

1. 把整个 `astrbot_plugin_fund_board` 文件夹放到 AstrBot 的 `data/plugins/` 目录下。
2. 重启 AstrBot，或者在 WebUI 的插件管理里重载插件。AstrBot 会自动安装 `requirements.txt` 中的依赖（rapidfuzz）。
3. 截图导入需要支持图片输入的大模型，例如 GPT-4o、Qwen-VL、GLM-4V。可以在插件配置的「截图识别使用的模型」里指定；不指定时使用当前会话的对话模型。

## 指令

指令组为 `/fund`，别名 `/基金`。

| 指令 | 说明 |
|---|---|
| `/fund board`（`/fund 看板`） | 持仓看板：每只基金的当日涨跌、市值、今日盈亏、累计盈亏，以及合计 |
| `/fund list` | 持仓明细（份额、成本） |
| `/fund add 代码 持有金额 [持有收益]` | 添加或更新一只基金，例如 `/fund add 016370 41200 -23500`，金额支持 `4.12万` |
| `/fund del 代码` | 删除一只基金 |
| `/fund clear 确认` | 清空全部持仓 |
| `/fund info 代码` | 单只基金的净值、估值和近 1/3/6/12 个月收益 |
| `/fund import`（`/fund 导入`） | 截图一键导入 |
| `/fund help` | 帮助 |

### 添加持仓时为什么填金额和收益

App 持仓页直接显示「持有金额」和「持有收益」，照抄这两个数最方便。插件按最新净值换算份额：份额 = 金额 ÷ 净值，成本 = 金额 − 收益。

### 截图导入流程

1. 发送 `/fund import`，可以同时附上截图。
2. 继续发截图（可以分多条），发完后回复「完成」。
3. 机器人列出识别结果，需要核对：
   - ✅ 已匹配到基金
   - ❓ 有多只同名（例如 A/C 份额），回复 `2a` / `2b` 进行选择
   - ⏳ 有确认中的金额，默认不导入，回复 `加 N` 可以导入
   - ❌ 没有匹配到基金，回复 `改 N 代码 016370` 手动补充
   - 还可以用 `删 N`、`改 N 金额 30000`、`改 N 收益 -2000` 修改
4. 回复「确认」会合并到现有持仓，同一代码按截图覆盖；回复「确认覆盖」会先清空现有持仓再导入；回复「取消」退出。

整个过程 5 分钟内没有操作会自动结束。

## 看板说明

- **估**：盘中估值；**净**：官方净值。如果标签带日期（例如 `净11-05`），说明今天的净值还没更新，常见于 QDII 基金和周末。
- 今天的净值没有更新的基金，其涨跌不计入「今日」合计，避免把不同日期的涨跌混在一起。
- 群聊里默认只显示百分比、不显示金额，可以在配置里打开金额显示；私聊始终显示完整金额。

## 配置项

| 配置 | 默认值 | 说明 |
|---|---|---|
| 截图识别使用的模型 | 空 | 留空时使用当前会话的模型 |
| 群聊中显示金额 | 关 | |
| 单次导入最多截图数 | 6 | |
| 行情接口超时（秒） | 10 | |

## 数据来源与限制

- 估值和净值来自天天基金的批量估值接口 `fundcomapi.tiantianfunds.com/mm/newCore/FundValuationLast`，基金列表来自 `fund.eastmoney.com/js/fundcode_search.js`，阶段收益来自 `fund.eastmoney.com/pingzhongdata/{代码}.js`。这些都是非官方公开接口，可能变动；接口相关代码都集中在 `datasource.py`。
- QDII 基金没有盘中估值，净值通常延迟 1～2 个交易日。
- 持仓保存在 `data/plugin_data/astrbot_plugin_fund_board/fund_board.db`，按「平台 ID + 用户 ID」隔离。
- 截图会发送给你配置的大模型服务商进行识别。
