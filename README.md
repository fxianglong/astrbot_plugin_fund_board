# 基金持仓看板 astrbot_plugin_fund_board

这是一个 AstrBot 插件，可以在聊天里记录基金持仓、查看盘中估值和盈亏，支持发送 App 持仓页截图一键导入持仓，记录加仓和赎回，并在交易日定时推送日报和回撤提醒；还能穿透基金重仓股，检查组合的集中度和持仓重叠；每周生成带 AI 点评的周报，也可以直接用自然语言问机器人自己的持仓情况。

## 安装

1. 把整个 `astrbot_plugin_fund_board` 文件夹放到 AstrBot 的 `data/plugins/` 目录下。
2. 重启 AstrBot，或者在 WebUI 的插件管理里重载插件。AstrBot 会自动安装 `requirements.txt` 中的依赖（rapidfuzz）。
3. 截图导入需要支持图片输入的大模型，例如 GPT-4o、Qwen-VL、GLM-4V。可以在插件配置的「截图识别使用的模型」里指定；不指定时使用当前会话的对话模型。

## 指令

指令组为 `/fund`，别名 `/基金`。

| 指令 | 说明 |
|---|---|
| `/fund board`（`/fund 看板`） | 持仓看板：每只基金的当日涨跌、市值、今日盈亏、累计盈亏，以及合计 |
| `/fund list` | 持仓明细（份额、成本） |
| `/fund add 代码 持有金额 [持有收益]` | 添加或更新一只基金，例如 `/fund add 016370 41200 -23500`，金额支持 `4.12万` |
| `/fund del 代码` | 删除一只基金 |
| `/fund clear 确认` | 清空全部持仓 |
| `/fund info 代码` | 单只基金的净值、估值和近 1/3/6/12 个月收益 |
| `/fund import`（`/fund 导入`） | 截图一键导入 |
| `/fund buy 代码 金额 [净值]` | 记录加仓，不填净值按最新净值估算份额 |
| `/fund sell 代码 份额\|全部 [净值]` | 记录赎回，按平均成本法计算实现盈亏 |
| `/fund trades [代码]` | 最近 15 条交易记录 |
| `/fund push on\|off` | 在当前会话开启或关闭每日推送 |
| `/fund push now` | 立即生成一次日报（不影响定时推送的状态） |
| `/fund alert` | 查看提醒设置 |
| `/fund alert day 3` | 组合单日跌幅超过 3% 时提醒，0 表示关闭 |
| `/fund alert dd 20` | 组合或单只基金回撤超过 20% 时提醒，0 表示关闭 |
| `/fund overlap` | 重仓股穿透与基金两两重叠分析 |
| `/fund check [img\|text]` | 组合体检：集中度、行业、个股穿透、重叠、回撤、经理任职 |
| `/fund board img` | 图片版看板（`text` 强制文字） |
| `/fund weekly`（`/fund 周报`） | 本周周报，含 AI 点评 |
| `/fund help` | 帮助 |

### 添加持仓时为什么填金额和收益

App 持仓页直接显示「持有金额」和「持有收益」，照抄这两个数最方便。插件按最新净值换算份额：份额 = 金额 ÷ 净值，成本 = 金额 − 收益。

### 截图导入流程

1. 发送 `/fund import`，可以同时附上截图。
2. 继续发截图（可以分多条），发完后回复「完成」。
3. 机器人列出识别结果，需要核对：
   - ✅ 已匹配到基金
   - ❓ 有多只同名（例如 A/C 份额），回复 `2a` / `2b` 进行选择
   - ⏳ 有确认中的金额，默认不导入，回复 `加 N` 可以导入
   - ❌ 没有匹配到基金，回复 `改 N 代码 016370` 手动补充
   - 还可以用 `删 N`、`改 N 金额 30000`、`改 N 收益 -2000` 修改
4. 回复「确认」会合并到现有持仓，同一代码按截图覆盖；回复「确认覆盖」会先清空现有持仓再导入；回复「取消」退出。

整个过程 5 分钟内没有操作会自动结束。

## 每日推送与提醒

在想接收推送的会话里发送 `/fund push on`。建议在私聊里开启；在群里开启时，推送只显示百分比。

| 时间（北京时间，可配置） | 内容 |
|---|---|
| 交易日 15:05 | 收盘估值版看板；按估值单日跌幅超过阈值时附带提醒 |
| 交易日 21:30 起 | 净值日报：等今天的净值出齐后推送，没出齐就每 30 分钟重试，最晚到 23:30 用已公布的部分推送 |

周末不推送。节假日根据"今天有没有估值或净值"自动判断，不需要维护节假日表。只持有 QDII 的用户在晚上不会收到净值日报，因为 QDII 当天没有净值。

净值日报附带三类提醒：

- **组合单日跌幅**：今日组合跌幅超过 `day` 阈值（默认 3%）。
- **组合回撤**：插件把每天的组合涨跌连乘成一个净值指数（从开启推送后的第一份日报开始记录，加仓和赎回不影响它），计算较最高点的回撤。
- **单只基金回撤**：用近一年的累计净值计算较最高点的回撤（累计净值不受分红影响）。

回撤提醒按档位去重：超过阈值时提醒一次，之后每加深 5 个百分点再提醒一次，回撤回到阈值以下后重置，不会每天重复发同一条。

提醒只描述数据，不给出操作建议。

## 组合分析与体检

`/fund overlap` 和 `/fund check` 会逐只获取基金最新一期季报的前十大重仓股（含所属行业）、现任经理、股票仓位和近一年净值走势，然后计算：

| 指标 | 算法 |
|---|---|
| 穿透个股暴露 | Σ（基金市值 × 该股票占基金净值比例），按金额排序 |
| 行业分布 | 穿透金额按行业汇总，占已披露重仓股的比例 |
| 两两重叠度 | 两只基金共同重仓股的净值占比，逐只取较小值后求和 |
| 有效基金数 | 1 ÷ Σ（各基金占组合比例²），越接近基金只数说明资金越分散 |
| 近一年回撤 | 近一年累计净值较最高点的跌幅 |

体检的「发现」只陈述数据事实，触发条件是：单只基金占组合超过 40%；有效基金数低于 2.5；单一行业占已披露重仓股超过 40%；单只股票穿透后占组合超过 10%；两只基金重叠度超过 30%；近一年回撤超过 30%；现任经理任职不足一年。阈值在 `analysis.py` 顶部。

局限：基金只披露前十大重仓股，通常只覆盖基金 30%～70% 的仓位，而且季报有 1～3 个月滞后。体检结果里会注明数据截止日和覆盖比例。债券、货币基金没有股票持仓，不参与穿透。

## 图片模式

在插件配置中打开「看板和体检默认发图片」后，`/fund board`、`/fund check` 和每日推送都会以图片发送；提醒内容仍以文字附在图片后面。不开启时，也可以在指令后加 `img` 临时出图，例如 `/fund board img`。

图片由 AstrBot 的文转图服务渲染（WebUI 配置里的 t2i 设置）。渲染失败时会自动改发文字。配色遵循 A 股习惯：红涨绿跌。

## 周报

开启每日推送的用户，每周六 10:00（可配置）会收到一份周报，也可以随时发 `/fund weekly` 生成。周报内容：

- 本周组合涨跌和估算盈亏，以及每天的组合涨跌（每日数据来自净值日报，需要开启推送才有）；
- 每只基金本周涨跌，拖累最大和贡献最大的基金；
- 本周的买入和卖出记录；
- 体检发现的要点；
- 一段 AI 点评。

本周涨跌按累计净值计算（本周最后一个净值 ÷ 上周最后一个净值 − 1），盈亏按当前持仓估算。如果本周中途加仓或赎回过，盈亏会有偏差。

AI 点评的边界：系统提示词要求大模型只描述数据，不预测后市，不给操作建议。生成后插件会再过滤一遍，凡是含有「建议、加仓、减仓、止损、买入、卖出」等字眼的句子都会删掉。没有可用模型或调用失败时，周报照常发送，只是不带点评。

## 自然语言查询

插件向 AstrBot 注册了三个函数工具。只要你的对话模型支持函数调用，正常聊天时就可以直接问：

| 工具 | 适合的问题 |
|---|---|
| `fund_get_portfolio` | 我今天亏了多少？我哪只基金亏得最多？016370 现在怎么样？ |
| `fund_lookup` | 帮我看看 110011 这只基金 |
| `fund_checkup` | 我的持仓集中吗？这几只基金是不是买重复了？我实际买了哪些股票？ |

工具只读取提问者本人的持仓。在群聊里只返回百分比，并提示模型不要透露金额。工具返回的数据末尾都附有一句「不要给出操作建议」的说明。在插件配置里可以关闭这三个工具。

## 加仓与赎回

- `buy` 按金额记录：份额 = 金额 ÷ 净值，成本增加买入金额。基金公司实际确认的份额可能略有差异，确认后可以用 `/fund add` 按 App 里的数字校准。
- `sell` 按份额记录，使用平均成本法：卖出部分对应的成本按比例扣减，卖出所得与这部分成本的差额记为实现盈亏。看板底部会显示已实现盈亏合计。
- 记录交易时，手续费暂时不单独计算。

## 看板说明

- **估**：盘中估值；**净**：官方净值。如果标签带日期（例如 `净11-05`），说明今天的净值还没更新，常见于 QDII 基金和周末。
- 今天的净值没有更新的基金，其涨跌不计入「今日」合计，避免把不同日期的涨跌混在一起。
- 群聊里默认只显示百分比、不显示金额，可以在配置里打开金额显示；私聊始终显示完整金额。

## 数据来源与限制

- 重仓股来自天天基金移动端接口 `fundmobapi.eastmoney.com/FundMNewApi/FundMNInverstPosition`。
- 估值和净值来自天天基金的批量估值接口 `fundcomapi.tiantianfunds.com/mm/newCore/FundValuationLast`，基金列表来自 `fund.eastmoney.com/js/fundcode_search.js`，阶段收益来自 `fund.eastmoney.com/pingzhongdata/{代码}.js`。这些都是非官方公开接口，可能变动；接口相关代码都集中在 `datasource.py`。
- QDII 基金没有盘中估值，净值通常延迟 1～2 个交易日。
- 持仓保存在 `data/plugin_data/astrbot_plugin_fund_board/fund_board.db`，按「平台 ID + 用户 ID」隔离。
- 截图会发送给你配置的大模型服务商进行识别。
